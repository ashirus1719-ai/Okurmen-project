# Техническое задание
# Веб-приложение образовательной IT-академии «Окуучулар IT»

> Рабочее название проекта: **Окурмен IT**  
> Тип продукта: современная образовательная платформа / LMS + лендинг + CRM/админ-панель + система обучения  
> Основные роли: **Администратор, Ментор, Ученик**  
> Язык интерфейса: кыргызский / русский / английский (архитектура должна позволять добавлять языки)  
> Формат обучения: гибридный — онлайн, офлайн и смешанный  
> Главный приоритет: **визуально насыщенный интерфейс с полноценными анимациями, интерактивным фоном, микроанимациями и высокой плавностью работы.**

---

# 1. Цель проекта

Создать полноценное веб-приложение IT-академии, которое одновременно выполняет функции:

- презентационного сайта академии;
- каталога курсов;
- LMS-платформы;
- личного кабинета ученика;
- кабинета ментора;
- системы тестирования;
- системы домашних заданий;
- мини-игровой платформы;
- системы бронирования;
- системы оплаты;
- CRM для работы с учениками;
- административной панели;
- системы коммуникации между учеником и ментором;
- аналитической системы;
- базы выпускников;
- площадки для отзывов;
- информационного сайта академии.

Система должна выглядеть не как обычный корпоративный сайт, а как **современный технологичный продукт**, где движение интерфейса, фоновые эффекты, переходы, карточки, кнопки и переключатели создают ощущение живого приложения.

# 2. Критическое требование проекта — анимации

## 2.1. Общий принцип

Анимация является одной из основных частей дизайна, а не дополнительным украшением.

На всех основных страницах должны присутствовать:

- плавное появление блоков;
- scroll-анимации;
- hover-анимации;
- интерактивные кнопки;
- анимированные карточки;
- плавные переходы между страницами;
- animated counters;
- floating elements;
- parallax;
- animated gradients;
- background particles;
- плавное изменение цветов;
- микроанимации иконок;
- анимации загрузки;
- skeleton loading;
- анимированные уведомления;
- интерактивные переключатели.

При этом анимации не должны мешать чтению, навигации и работе на слабых устройствах.

# 3. Главный анимированный фон

## 3.1. Фон лендинга

Фон должен быть выполнен в стиле:

**black + white / dark + light + yellow accent**

Основная идея:

- черно-белый динамический градиент;
- большие мягкие световые пятна;
- желтые светящиеся элементы;
- полупрозрачные пузыри;
- частицы;
- floating yellow balls;
- blur;
- glow;
- мягкое движение элементов.

## 3.2. Желтые шарики

На фоне периодически появляются желтые круглые элементы.

Поведение:

1. появляются снизу;
2. медленно поднимаются вверх;
3. немного двигаются влево/вправо;
4. меняют прозрачность;
5. часть шариков увеличивается;
6. часть уменьшается;
7. некоторые исчезают за верхней границей;
8. цикл запускается снова.

Эффект должен быть бесконечным.

Шарики не должны перекрывать текст.

## 3.3. Дополнительные эффекты

Можно использовать:

- glow;
- blur;
- noise;
- moving gradient;
- radial gradient;
- particles;
- glassmorphism;
- light beams;
- floating circles;
- animated lines;
- soft shadows.

# 4. Hero-блок лендинга

Главный экран должен занимать практически весь первый экран.

## 4.1. Главный H1

H1 должен автоматически менять текст примерно каждые **3 секунды**.

Пример:

> Учись. Создавай. Развивайся.

Через 3 секунды:

> Стань IT-специалистом.

Затем:

> Создавай своё будущее.

Затем:

> Оку IT менен башта.

Каждый текст:

- появляется плавно;
- предыдущий текст исчезает;
- используется fade + slide;
- допускается небольшая scale-анимация;
- разные слова могут иметь разные цвета;
- основной accent — желтый.

Важно: текст не должен резко прыгать при изменении длины. Высота блока должна быть зарезервирована.

# 6. Переключатель светлой / темной темы

Переключатель должен быть интерактивным.

Не использовать обычный checkbox.

Внутри переключателя:

### Светлая тема

- голубое небо;
- солнце;
- облака;
- мягкий фон.

### Темная тема

- ночное небо;
- луна;
- звезды;
- темный фон.

При переключении:

- солнце плавно превращается/уезжает;
- появляется луна;
- звезды становятся видимыми;
- фон плавно меняется;
- цвета интерфейса переходят без резкого переключения.

Настройка сохраняется в localStorage/профиле пользователя.

- тест;
- задание;
- мини-игру;
- посещение;



# 41. Безопасность

Обязательно:

- HTTPS;
- secure cookies;
- password hashing;
- rate limiting;
- CSRF protection;
- XSS protection;
- SQL injection protection;
- RBAC;
- server-side permission checks;
- audit log;
- login attempt protection;
- 2FA для администраторов;
- резервное копирование;
- секреты только на backend.

Критически важно:

**Нельзя защищать админку только скрытием кнопки.**

Нельзя:

- оставлять пустые страницы;
- использовать случайные fake testimonials как реальные;
- показывать admin navigation обычным студентам;
- доверять frontend для проверки прав;
- хранить секреты Telegram/payment в frontend;
- делать тяжелые бесконечные анимации без оптимизации;
- ломать интерфейс на мобильном;
- использовать разные стили кнопок в разных разделах;
- делать резкие переходы;
- создавать layout shift при смене H1.

# 84. Главный визуальный принцип проекта

**Окурмен IT должен ощущаться как живое технологичное приложение.**

Необходимо избегать:

> «обычный сайт с белым фоном, текстом и несколькими кнопками».

Целевой эффект:

> **живой образовательный digital-продукт с движущимся фоном, световыми эффектами, интерактивными кнопками, карточками, микроанимациями, игровыми элементами, красивыми переходами и современной LMS-архитектурой.**

При этом визуальные эффекты не должны снижать скорость, читаемость и удобство.

# 86. Финальное требование

При разработке необходимо воспринимать **анимацию как часть UI/UX-системы**, а не как декоративный эффект.

Особое внимание уделить:

1. Анимированному Hero.
2. Меняющемуся H1 каждые 3 секунды.
3. Плавающим желтым шарам.
4. Динамическому черно-белому градиентному фону.
5. Animated light/glow.
6. Анимированному переключателю день/ночь.
7. Hover-анимациям.
8. Page transitions.
9. Scroll reveal.
10. Animated course cards.
11. Animated progress.
12. Animated achievements.
13. Loading/skeleton.
14. Animated notifications.
15. Mobile menu animation.
16. Modal/drawer animation.
17. Игровым эффектам.
18. Success/error states.
19. Плавным изменениям темы.
20. Общей согласованности motion design.

**Все анимации должны быть плавными, современными, оптимизированными и единообразными во всем приложении.**

Главный результат: **не просто функциональная LMS, а полноценная современная визуальная IT-платформа Окурмен IT.**
